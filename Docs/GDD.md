# 수박 게임(Suika Game) - Game Design Document

## 1. 게임 개요

### 한 줄 요약
**물리 기반 과일 머지 퍼즐 게임으로, 떨어지는 과일을 조작하여 같은 종류끼리 만나면 합쳐지는 메커닉을 통해 궁극의 목표인 '수박'을 만드는 게임입니다.**

### 코어 루프
1. 플레이어가 다음 과일을 확인한다
2. 과일을 떨어뜨릴 위치를 선택한다
3. 과일을 떨어뜨린다
4. 물리 연산에 의해 과일이 떨어지고 다른 과일과 상호작용한다
5. 같은 종류의 과일이 충돌하면 더 큰 과일로 머지된다
6. 점수를 획득한다
7. 과일이 컨테이너를 벗어나지 않는 한 1번으로 돌아간다
8. 과일이 컨테이너 상단을 넘으면 게임 오버

---

## 2. 핵심 메커닉

### 2.1 떨어뜨리기 (Drop Mechanics)
- **입력**: 플레이어가 화면 상단의 X좌표를 선택하여 과일을 떨어뜨림
- **시스템**: 선택된 위치 위에서 과일이 떨어지기 시작
- **제약사항**: 떨어뜨릴 수 있는 과일의 최대 크기는 감(Persimmon) 단계까지만 직접 투입 가능

### 2.2 충돌 및 물리 연산 (Collision & Physics)
- **물리 엔진**: Unity의 Rigidbody 2D를 활용하여 현실적인 물리 시뮬레이션 구현
- **특성**:
  - 과일은 중력에 의해 떨어진다
  - 과일 간 충돌 시 물리적 반작용이 발생
  - 과일은 컨테이너 벽에 충돌하여 튕겨나간다
  - 과일 간의 마찰력으로 인한 움직임 감소

### 2.3 머지 (Merge Mechanics)
- **머지 조건**: 정확히 같은 종류의 두 과일이 접촉할 때 발동
- **머지 프로세스**:
  1. 두 과일이 접촉 감지
  2. 두 과일이 사라짐
  3. 접촉 위치에서 다음 단계 과일 생성
  4. 점수 추가
  5. 연쇄 머지 가능 (새로 생성된 과일이 주변 과일과 즉시 머지될 수 있음)

### 2.4 게임 오버 (Game Over Condition)
- **패배 조건**: 과일이 컨테이너의 상단 경계를 넘어가면 게임 오버
- **게임 오버 시**:
  - 플레이어의 최종 점수 표시
  - 결과 화면 표시
  - "재시작" 또는 "게임 종료" 선택 옵션 제공

## 3. 과일 단계 (Fruit Progression)

### 3.1 과일 단계 목록
총 **11단계**의 과일이 존재하며, 단계별로 크기와 점수가 증가합니다.

| 단계 | 과일 이름 | 영문명 | 크기 (상대값) | 직접 투입 가능 | 비고 |
|------|---------|--------|-----------|------------|------|
| 1 | 체리 | Cherry | 1.0x | ✓ | 가장 작은 과일 |
| 2 | 딸기 | Strawberry | 1.3x | ✓ | |
| 3 | 포도 | Grape | 1.6x | ✓ | |
| 4 | 한라봉 | Mandarin | 2.0x | ✓ | 오렌지로도 표현 가능 |
| 5 | 감 | Persimmon | 2.5x | ✓ | 직접 투입 가능한 최대 크기 |
| 6 | 사과 | Apple | 3.0x | ✗ | 머지로만 생성 가능 |
| 7 | 배 | Pear | 3.5x | ✗ | 머지로만 생성 가능 |
| 8 | 복숭아 | Peach | 4.0x | ✗ | 머지로만 생성 가능 |
| 9 | 파인애플 | Pineapple | 4.5x | ✗ | 머지로만 생성 가능 |
| 10 | 멜론 | Melon | 5.0x | ✗ | 머지로만 생성 가능 |
| 11 | 수박 | Watermelon | 6.0x | ✗ | 최종 목표 과일 |

### 3.2 크기 비율
- 각 단계별 과일은 이전 단계 과일 대비 **1.25배** 크기 증가
- 반지름 기준: Stage_N의 반지름 = Stage_1의 반지름 × (1.25 ^ (N-1))
- 외형상 구분이 쉽도록 충분한 크기 차이 유지

### 3.3 합쳐지는 규칙
- **기본 규칙**: 같은 종류 × 2 = 다음 단계 과일 1개
  - 체리 + 체리 = 딸기
  - 딸기 + 딸기 = 포도
  - ... (반복)
  - 멜론 + 멜론 = 수박
  
- **수박의 경우**: 수박 + 수박 = 사라짐 (추가 점수 획득)

## 4. 점수 및 승패 규칙

### 4.1 점수 시스템
- **점수 획득**: 과일이 머지될 때만 점수 획득
- **점수 계산**:
  - 기본 점수 = 생성된 과일의 단계 × 10
  - 예시:
    - 체리 2개 머지 → 딸기 생성 → 2단계 × 10 = 20점
    - 사과 2개 머지 → 배 생성 → 7단계 × 10 = 70점
    - 수박 2개 머지 → 사라짐 → 11단계 × 10 = 110점

- **연쇄 머지 보너스**: 연속으로 머지가 발생할 때 보너스 점수
  - 단일 머지: 기본 점수
  - 연쇄 머지 (2회): 기본 점수 × 1.1
  - 연쇄 머지 (3회): 기본 점수 × 1.2
  - 연쇄 머지 (4회 이상): 기본 점수 × 1.3

### 4.2 게임 승리 조건
- **궁극적 목표**: 수박(Watermelon) 1개 이상 생성
- **달성 시**: "성공" 화면 표시 및 최종 점수 표시
- **추가 도전**: 수박 생성 후에도 계속 플레이 가능하며, 추가 점수 획득 기회 제공

### 4.3 게임 패배 조건
- **패배 시점**: 어떤 과일이 컨테이너 상단 경계를 넘어갈 때
- **패배 처리**: 현재까지의 점수와 최고 기록(High Score) 비교 표시

## 5. 화면 및 UI 구성

### 5.1 메인 게임 화면 레이아웃
```
┌─────────────────────────────────────┐
│  SCORE: 12500  │  NEXT: [포도]    │  (상단 UI)
├─────────────────────────────────────┤
│                                     │
│         [게임 컨테이너]             │  
│         (과일이 떨어지는 공간)       │
│                                     │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

### 5.2 UI 요소 상세 설명

#### 상단 UI 바
- **좌측**: "SCORE: {현재 점수}"
  - 폰트 크기: 중간(32pt)
  - 색상: 흰색 또는 검은색 (배경에 따라)
  - 실시간 업데이트

- **우측**: "NEXT: [다음 과일 아이콘]"
  - 다음에 떨어질 과일 미리보기
  - 아이콘 크기: 작음(40x40px)
  - 플레이어의 전략 수립 지원

#### 게임 컨테이너
- **크기**: 화면의 대부분 차지
- **배경**: 밝은 색상 (흰색, 밝은 노란색 등)
- **경계**: 명확한 검은색 테두리 또는 목재 텍스처
- **과일 표시**: 컬러풀한 과일 이미지
- **위치 가이드**: 마우스 위치에서 다음 과일이 떨어질 위치를 시각적으로 표시 (투명한 프리뷰)

### 5.3 게임 오버 화면
```
┌─────────────────────────────────────┐
│         GAME OVER                   │
│                                     │
│    최종 점수: 25480                 │
│    최고 기록: 30120                 │
│                                     │
│    [다시 시작]  [메뉴로]            │
└─────────────────────────────────────┘
```

### 5.4 성공 화면
```
┌─────────────────────────────────────┐
│         SUCCESS!                    │
│      🍉 수박을 만들었습니다! 🍉     │
│                                     │

│    최고 기록: 45820                 │
│                                     │
│    [계속 플레이]  [메뉴로]          │
└─────────────────────────────────────┘
```

### 5.5 일시 정지 화면 (선택사항)
```

│                                     │
│    [계속]  [처음부터]  [메뉴로]     │
└─────────────────────────────────────┘
```

## 6. 톤 & 분위기

### 6.1 색감 (Color Palette)
- **배경색**: 밝고 따뜻한 톤
  - 주 색상: #FFF8DC (Cornsilk) 또는 #FFFACD (Lemon Chiffon)
  - 대안: 밝은 하늘색 #E0F6FF

- **컨테이너 경계**: 따뜻한 갈색
  - 색상: #8B4513 (Saddle Brown) 또는 #D2691E (Chocolate)
  - 목재 느낌으로 자연스러움 연출

- **과일 색상**:
  - 체리: #E91E63 (진한 분홍)
  - 딸기: #FF6B6B (밝은 빨강)
  - 포도: #9C27B0 (보라)
  - 한라봉: #FF9800 (주황)
  - 감: #FF6F00 (어두운 주황)
  - 사과: #4CAF50 (녹색)
  - 배: #8BC34A (연두)
  - 복숭아: #FFAB91 (살구색)
  - 파인애플: #FFD700 (황금색)
  - 멜론: #00C853 (밝은 초록)
  - 수박: #E53935 (빨강) + #388E3C (초록) 조합

### 6.2 아트 방향 (Art Direction)
- **스타일**: 귀여운 캐주얼 스타일 (Cute Casual)
  - 과일의 외형: 동글동글하고 부드러운 형태
  - 명암: 약간의 그라데이션으로 입체감 표현
  - 효과: 과일에 작은 하이라이트 추가하여 생생함 강조

- **과일 디자인**:
  - 모든 과일은 원형(2D 기준)으로 통일
  - 각 과일마다 고유한 텍스처 또는 패턴 (예: 딸기의 씨, 수박의 줄무늬)
  - 머지 시 팝(Pop) 애니메이션 또는 플래시 이펙트

- **UI 폰트**: 친근하고 읽기 쉬운 폰트
  - 추천: 동글동글한 무선 폰트 (예: Arial Rounded, Gill Sans)
  - 크기: 명확한 계층 구조

### 6.3 음향 및 BGM 느낌 (Audio Direction)
- **BGM (Background Music)**:
  - 장르: 가볍고 즐거운 팝 또는 인디팝
  - 분위기: 밝고 긍정적
  - 템포: 중간 속도 (100~120 BPM)
  - 특징: 반복되는 멜로디로 몰입감 유지, 신나는 느낌
  - 추천 스타일: 8-bit 레트로 또는 현대적 캐주얼 스타일

- **효과음 (SFX)**:
  - **과일 떨어지는 소리**: 가볍고 부드러운 소리 (윤윤한 톤)
  - **충돌음**: 과일의 크기에 따라 다른 음높이의 "통통" 소리
  - **머지음**: 즐거운 "핑~" 또는 "쪨!" 소리 + 짧은 승리감 효과음
  - **게임 오버음**: 아쉬운 느낌의 낮은 음 (드라마틱하지 않게)
  - **수박 달성음**: 밝고 신나는 승리 팬파레 (짧은 멜로디)
  - **UI 클릭음**: 가벼운 "탁" 소리

- **전반적인 사운드 톤**:
  - 자극적이지 않으면서도 중독성 있음
  - 플레이어의 성취감을 음향으로 표현
  - 긴장감 없이 편안함과 재미 위주

## 7. 기술 사양 (Technical Specifications)

### 7.1 개발 환경
- **엔진**: Unity 6.3
- **언어**: C#
- **플랫폼**: PC (Windows, macOS), 확장 시 모바일 고려

### 7.2 물리 시뮬레이션
- **물리 엔진**: Unity 2D Physics (Rigidbody2D)
- **중력**: 9.81 m/s² (또는 게임플레이 느낌에 맞게 조정)
- **마찰력**: 적절한 마찰력으로 과일의 움직임 제어
- **반발력(Bounciness)**: 낮게 설정하여 현실적인 움직임

### 7.3 해상도 및 종횡비
- **목표 해상도**: 1080p (1920x1080) 기준
- **UI 스케일링**: 다양한 해상도 지원
- **컨테이너 비율**: 정사각형에 가까운 형태 (너비:높이 = 9:11 또는 비슷)

## 8. 향후 확장 가능성 (Future Expansion)

- **난이도 조정**: 점수 기준 또는 시간 제한 모드
- **스페셜 아이템**: 특정 과일만 제거하는 아이템 등
- **리더보드**: 온라인 점수 순위표
- **사운드 온/오프**: 설정 메뉴에서 음량 조절
- **그래픽 설정**: 저사양 디바이스 지원을 위한 옵션
