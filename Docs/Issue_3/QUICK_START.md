# 🍉 수박게임 - 빠른 시작 가이드

이슈 #3 (과일 드롭 기능)을 빠르게 구현하는 방법입니다.

## 🚀 1단계: 자동 씬 설정 (권장)

Unity 에디터에서 다음 순서대로 진행하세요:

### 1.1 Unity 에디터 시작
- `Assets/Scenes/SampleScene.unity` 열기

### 1.2 자동 설정 실행
1. 메뉴에서 **Tools** → **Suika Game** → **Setup Scene for Issue #3** 클릭
2. 콘솔에 "✅ 씬 자동 설정이 완료되었습니다!" 메시지 확인

### 1.3 테스트
- **Play 버튼** 클릭
- 마우스를 클릭하면 과일이 생성되고 떨어집니다
- 같은 종류 과일끼리 만나면 다음 단계 과일로 합쳐집니다

## 🎮 테스트 시나리오

### 기본 테스트
1. Play 버튼 클릭
2. 게임 화면의 다양한 위치에서 마우스 클릭
3. 과일이 생성되고 물리 연산으로 떨어지는지 확인
4. Stop 버튼 클릭

### 머지 테스트
1. 같은 위치에서 같은 종류의 과일 2개 생성
2. 과일이 만나면 다음 단계 과일로 합쳐지는지 확인
3. 점수가 증가하는지 콘솔에서 확인

### 게임오버 테스트
1. 계속해서 과일을 생성하여 쌓기
2. 과일이 상단 경계(Y=6.5)를 넘으면 게임 오버
3. 콘솔에 "게임 오버!" 메시지 확인

## 🐛 문제 해결

### Q: "Setup Scene" 메뉴가 보이지 않습니다
**A:** 
- Unity 에디터가 완전히 로드될 때까지 기다리세요
- `Assets/Scripts/` 폴더의 모든 스크립트가 컴파일되었는지 확인하세요
- 콘솔에 컴파일 오류가 있으면 수정하세요

### Q: 과일이 생성되지 않습니다
**A:**
- 에러 메시지를 콘솔에서 확인하세요
- FruitPrefab이 `Assets/` 폴더에 있는지 확인하세요
- FruitSpawner의 Fruit Prefab이 할당되었는지 확인하세요

### Q: 과일이 떨어지지 않습니다
**A:**
- Rigidbody2D의 Body Type이 "Dynamic"인지 확인하세요
- Gravity Scale이 1로 설정되었는지 확인하세요
- Scene 뷰에서 과일의 콜라이더가 활성화되었는지 확인하세요

### Q: 머지가 작동하지 않습니다
**A:**
- 두 과일이 완전히 겹쳐야 머지됩니다
- Circle Collider 2D의 "Is Trigger"가 체크 해제되었는지 확인하세요
- 콘솔에 충돌 감지 메시지가 나타나는지 확인하세요
